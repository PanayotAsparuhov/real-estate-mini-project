# Анализ на големи данни за недвижими имоти

Демонстрационен проект за прогнозиране на цена на недвижим имот чрез C# и ML.NET.

## Описание
Проектът реализира малък пример за regression задача върху данни за недвижими имоти.

Използвани признаци:
- площ
- брой стаи
- етаж
- година на строеж
- квартал
- близост до метро
- тип строителство

Целта е да се прогнозира цената на имот въз основа на тези характеристики.

## Използвани технологии
- C#
- ML.NET
- FastTree regression model

## Dataset
Използван е `properties.csv`, съдържащ малък демонстрационен набор от данни за имоти и техните цени.

## Резултати
След обучението на модела са получени следните метрики:
- R² = 0.7898
- MAE = 37632.50
- RMSE = 42531.74# Анализ на големи данни за недвижими имоти
